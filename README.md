# 1c-crserver-manager

**1c-crserver-manager** — это инструмент для автоматизации и упрощения администрирования сервера хранилища конфигураций 1С:Предприятие (`crserver`) на серверах под управлением ОС Linux. 

Скрипт решает проблему отсутствия удобных штатных инструментов под Linux для быстрого развертывания, управления несколькими службами хранилищ, настройки автозапуска и резервного копирования.

---

## 🌟 Ключевые возможности

* **Управление службами (systemd):** Автоматическая генерация и регистрация systemd-юнитов для серверов хранилища.
* **Мультисерверность:** Возможность запуска нескольких изолированных экземпляров `crserver` на одном сервере (на разных портах и с разными каталогами данных).
* **Простое развертывание:** Быстрое создание новых хранилищ конфигураций одной командой.
* **Управление жизненным циклом:** Удобный запуск, остановка, перезагрузка и проверка статуса служб.
* **Управление правами:** Автоматическая установка правильных прав доступа к директориям хранилища (для пользователя `usr1cv8`).

## 📋 Системные требования

* **ОС:** Linux с системой инициализации `systemd` (Debian, Ubuntu, CentOS, RHEL, Ред ОС, Astra Linux и др.).
* **1С:Предприятие:** Установленные пакеты сервера 1С (в частности, утилита `crserver`).
* **Права:** Права суперпользователя (`root` или `sudo`) для создания служб.
